Career Path AI Recommendation Agent

Overview
An AI-based career recommendation system developed using Python and Streamlit. The system provides personalized career suggestions by integrating a Large Language Model API.

Features
Interactive web interface using Streamlit
Groq LLM API integration
Structured prompt design
API response handling and validation

Technologies Used
Python
Streamlit
Groq API

How to Run code
pip install -r requirements.txt
streamlit run app.py
